The lightweight, system-wide,
keyboard-native, AI text processing framework

## ✨ Features ✨

### **Ultra-lightweight: Only ~150 MB, portable, no installer or admin rights required**

Ghostwriter is an extremely lean, standalone package. Simply download and run—entirely without installation,
registry entries, or admin privileges. Perfectly suited for running directly even on restrictive work or corporate computers.

### **The only full-featured in-text AI framework: Replaces text instantly with AI Output**

The end of tedious copy-paste marathons. Ghostwriter doesn’t operate in an isolated silo window, but right where your cursor is currently blinking—no matter if it's in Outlook, VS Code, WhatsApp, or your browser. Your text is analyzed on the spot and overwritten in real time by the AI result.

### **100% Keyboard-first: Built for seamless flow without touching the mouse**

Consistent headless design for power users. When you write, your hands are already on the keyboard—and that’s where they stay. No nested context menus, no tiny "Send" buttons. From highlighting the text to the final transformation, you control every step at lightning speed via shortcuts.

### **Ultra-fast: Under 50ms, works even on older hardware**

Speed is the core principle of the architecture. Less than 50 milliseconds elapse from pressing the hotkey to firing the request. The UI is completely pre-warmed; there are no loading stutters and no layout delays. The tool responds with such zero-latency responsiveness as if it were firmly anchored in the Windows kernel.

### **Universal Prompt: Execute ad-hoc commands directly from your typed text**

If you are missing a predefined prompt for a specific task, you simply write your instruction (e.g., <<make this shorter and more formal>>) directly alongside your text. The integrated marker parser recognizes the command, dynamically separates it from the rest of the content, and delivers exactly the desired result directly back into your text field.

### **Flexible UI: Minimalist popup with fuzzy search and number-key quick access**

If you need visual feedback, a Raycast-inspired, minimalist overlay opens up. Thanks to fuzzy search, you don't even have to type search terms accurately to find the right prompt. Alternatively, you can fire off your favorite prompts directly using the number keys, even before the window is fully visible.

### **Modern Visuals: Optional Windhawk C++ mod for native Windows DWM blur effects**

Instead of bloating the program with unstable UI hacks, the visuals are elegantly outsourced. A tailored Windhawk mod injects genuine macOS-level DWM composition blur directly into your window. This guarantees a gorgeous fluid-glass aesthetic with absolutely zero performance loss in the C# core.

### **Simple Config: Clean TOML configuration files**

No hidden registry keys and no bloated settings menus. Your API keys, models, hotkeys, and unlimited custom prompts live in extremely readable, structured TOML files. This makes backups, sharing your setups, and quick adjustments via any text editor child's play.
